# Hubs — منصة سياحية متعددة المدن

Next.js 14 (React + Node) · Supabase (Postgres + Storage) · Tailwind · Vercel

## التشغيل
1. أنشئ مشروع Supabase، وفي SQL Editor شغّل بالترتيب: `supabase/01_schema.sql` ثم `02_seed.sql` ثم `03_additions.sql`.
2. انسخ `.env.example` إلى `.env.local` وعبّي: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `JWT_SECRET`
   (واختياري `ANTHROPIC_API_KEY` لتفعيل المساعد الذكي؛ بدونه بيشتغل ببحث بسيط بالكلمات).
3. `npm install` ثم `npm run dev`.
4. سجّل حساب من الموقع ثم اجعله مالك من SQL Editor:
   `update users set role='owner' where email='you@example.com';`
   بعدها تضيف مشرفين وتحدد صلاحياتهم من الإدارة > المشرفون.
5. على Vercel: ضع نفس المتغيرات في Environment Variables.

## الموجود
**للمستخدم:** اختيار المدينة، الأماكن (فلتر نوع ومستوى)، العروض، غرف الفنادق، اكتشف المدينة، المواصلات (من/إلى)، خطط اليوم، الذكريات والتعليقات، المساعد، الشكاوى والاقتراحات (مع رد الإدارة كإشعار)، الإشعارات، توثيق الطالب، حساب (نقاط + أكواد QR + سجل الحركات)، عربي/إنجليزي لصفحات التصفح الرئيسية.

**الزيارة الموثقة:** كاميرا مباشرة + GPS داخل نطاق المكان + حد يومي + فاصل بين زيارتين + خصم تكرار كل N زيارات + مكافأة إتمام خطة اليوم.

**للتاجر:** طلب تسجيل بالسجل التجاري، أماكني (تدخل "قيد المراجعة" حتى يوافق الأدمن)، العروض، غرف الفندق، إحصاءات، التحقق من كود الخصم (استخدام واحد فقط) مع رسم ثابت لكل كود.

**للإدارة:** تقارير (مستخدمون، زيارات، أكواد، نقاط، أعلى الأماكن، مستحقات التجار)، طلبات التجار، توثيق الطلاب، إدارة الأماكن/المدن/الأنواع/اكتشف/المواصلات/الخطط/الذكريات، إعدادات النقاط والنسب، الشكاوى، المشرفون وصلاحياتهم (للمالك فقط). إضافة مدينة جديدة = سجل في المدن بدون تعديل كود.

## مش موجود
- **الدفع الإلكتروني:** محتاج قرار البوابة (Paymob/Fawry/Stripe...) ومفاتيح حساب تاجر. حقل `commission_rate` جاهز.
- الإنجليزية تغطي التصفح وتسجيل الدخول والتسجيل؛ رسائل النظام وصفحة حسابي ولوحات التاجر والأدمن عربي فقط.
- فوائد حساب الطالب الموثق (خصم/نقاط خاصة) لسه ما اتحددتش، الموجود هو التوثيق نفسه.

## ملاحظات
- الإحداثيات والنصوص في `02_seed.sql` مبدئية وتحتاج مراجعة، والمحلان التجريبيان لازم يتحذفوا قبل الإطلاق.
- الوصول للداتابيز كله من السيرفر بمفتاح service-role، والجداول عليها RLS مقفول، فمفيش وصول مباشر من المتصفح.
- التحقق بالكاميرا يعتمد على `capture` وعمر الصورة؛ بيمنع المعرض في أغلب الموبايلات لكنه مش مضمون 100%.
- الحدود على الدخول والتسجيل والمساعد والشكاوى والذكريات والتحقق من الأكواد محفوظة في ذاكرة السيرفر (لكل نسخة)؛ للإنتاج استخدم Upstash/Redis لو محتاج حد صارم.
- ملفات الـ SQL الثلاثة اتجربت على Postgres 16 محلي (بدون أخطاء، والـ seed يدخل مدينتين و7 أماكن و4 محطات خطة، وخصم النقاط الزائد بيترفض). الذي لم يُجرَّب هو الاتصال بـ Supabase نفسه والـ Storage.
- لسه ما اتجربش على Supabase حقيقي: أول تشغيل جرّب التسجيل ثم تسجيل زيارة ثم استبدال كود، وبلّغني بأي خطأ.
